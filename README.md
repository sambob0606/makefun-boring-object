A Python program that writes one original funny, true one-line review of the
dullest everyday object — the doorstop — for [The Most Boring Object,
Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)
on make.fun.

The line:

> The doorstop has spent six years holding the same door open, getting kicked into place twice a day, and its performance review just says "adequate".

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (148 characters, one line).
Stdlib only, no network, no reads outside the repo.
